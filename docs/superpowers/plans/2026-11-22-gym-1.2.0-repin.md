# Gym v1.2.0 Re-pin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Spire Learn's Standard combat work to Spire Gym v1.2.0 with its own rules epoch, a re-extracted state table, the compact combat observation, new panels and fresh baselines, so search distillation starts on the new version.

**Architecture:**
- The v1.1.1 series stays intact and reproducible: its contract, configs, recipe, state table and results are not edited.
- v1.2.0 gets a new Gym contract and runtime profile, a new state table and recipe file, new panels and two fresh PPO baselines.
- Learn's Standard stream reads the Gym's opt-in compact combat view; the dense path remains for the v1.1.1 series.

**Tech Stack:** Python 3.12, `spire_learn.neural`, Spire Gym v1.2.0 (`4d198064b3b568b6f0d08d6e3937d236fbc48e9b`) in the offline runtime container, `unittest` (`PYTHONPATH=src python3.12 -B -m unittest discover -s tests`).

**Spec:** There is no separate design document. The scope was approved by the user in conversation on 2026-11-22: re-pin to v1.2.0 including baseline re-runs, append measurements to the Gym beads, and update the search-distillation design. Gym references:

## Review Focus

1. **A v1.1.1 checkpoint or stream offered to a v1.2.0 config, or the reverse.** It must be rejected at preflight, before any runtime effect (Task 1).
2. **A compact observation that overflows a capacity.** The Gym raises a typed capacity fault. Learn must surface it as an error, never as a loss or a truncated observation (Task 3).
3. **Compact and dense disagreement.** For the same state, the compact view widened and zero-padded must give the network the same inputs as the dense view. A test compares policy outputs on both (Task 3).
4. **A relic whose counter rule changed in the entry-resource descriptor.** Extraction and the fuzz generator must follow the descriptor, and a mismatch with the alias table must fail a Gym-gated test, not pass silently (Task 2).
5. **A panel case whose search root is refused.** It is counted by refusal class, room kind and act, and still played by the heuristic fallback, as now (Task 4).
