# Gym v1.2.3 Re-pin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Spire Learn's Standard combat work from Gym v1.2.0 to v1.2.3 under a new rules epoch. This means rebuilding the state table, panels, search reference and both PPO baselines, and re-checking the search-teacher budgets. Stage 1's teacher runs, audit and gate G1 (Tasks 9–10) then run on the same Gym as labelling.

**Architecture:** The same shape as the v1.2.0 re-pin, which is already done, but lighter:
- The compact view, entry resources, panel machinery, turn cap and teacher tooling already exist.
- Descriptor fingerprints and PublicRoot digests are unchanged in v1.2.3. The rules ids move (Standard v9, M10/Gym66 v6, M9 v7), so the epoch is new and every stored record, table and checkpoint is regenerated.
- The release also brings typed `bound` faults (v1.2.2) and wider search-root coverage (v1.2.3: exact draw knowledge, Runic Dome roots, three new refusal classes).

**Tech Stack:** Python 3.12, the offline runtime container (`scripts/neural/runtime_container.py`), Spire Gym v1.2.3, and the existing Learn modules.

**Spec:** `docs/superpowers/specs/2026-11-21-search-distillation-design.md`. Its re-pin checkpoint was moved by the user's ruling (2026-11-25): re-pin between stage-1 Tasks 8 and 9, before the teacher runs. Precedent: `docs/superpowers/plans/2026-11-22-gym-1.2.0-repin.md`.

## Review Focus

1. **A checkpoint, table or panel from `gym-1.2.0` is presented under `gym-1.2.3`, or the reverse.** It must be refused with an error naming the epochs. Tested in Task 1.
2. **A typed `bound` fault.** It must surface as an error with its counter and limit in the message, never as a loss or a turn-cap censor. Tested in Task 1 with a fake, and natively in Task 3 if one occurs.
3. **The hard-coded revision lists** (carried item C2): `_TABLE_REVISIONS`, `entry_resources.EXPECTED_FINGERPRINTS`, the `run_states.py` revision tuples, the `SMOKES` keys and the descriptor pin outside `GymContract`. Each is updated or folded into `GymContract`. A test proves every site accepts v1.2.3 and still refuses an unknown revision. Task 1.
4. **The selection, final and boss panels on v1.2.3.** They must be rebuilt from the v1.2.3 table, with new identities that are recorded. Accidental reuse of v1.2.0 panel files is refused. Task 3.
5. **A changed search refusal profile.** The search reference and root measurements report the three new refusal classes by name, not as "other". Task 3.
