# Gym v1.2.4 Re-pin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Spire Learn's Standard combat work from Gym v1.2.0 to v1.2.4 under a new rules epoch. This means rebuilding the state table, panels, search reference and both PPO baselines, and re-checking the search-teacher budgets. Stage 1's teacher runs, audit and gate G1 (Tasks 9–10) then run on the same Gym as labelling.

**Architecture:** The same shape as the v1.2.0 re-pin, which is already done, but lighter:
- The compact view, entry resources, panel machinery, turn cap and teacher tooling already exist.
- Descriptor fingerprints and PublicRoot digests are unchanged in v1.2.4. The rules ids move (Standard v9, M10/Gym66 v6, M9 v7), so the epoch is new and every stored record, table and checkpoint is regenerated.
- The release also brings typed `bound` faults (v1.2.2) and wider search-root coverage (v1.2.3: exact draw knowledge, Runic Dome roots, three new refusal classes).

**Tech Stack:** Python 3.12, the offline runtime container (`scripts/neural/runtime_container.py`), Spire Gym v1.2.4, and the existing Learn modules.

**Spec:** `docs/superpowers/specs/2026-11-21-search-distillation-design.md`. Its re-pin checkpoint was moved by the user's ruling (2026-11-25): re-pin between stage-1 Tasks 8 and 9, before the teacher runs. Precedent: `docs/superpowers/plans/2026-11-22-gym-1.2.0-repin.md`.
